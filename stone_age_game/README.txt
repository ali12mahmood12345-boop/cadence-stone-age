CADENCE // STONE AGE SURVIVAL — V1

MISSION
Can the same Cadence brain learn to survive one complete day and night?

LEFT SIDE
A Stone Age survival world containing:
- trees
- rocks
- berry bushes
- rabbits
- day/night cycle
- hunger
- warmth
- energy
- health
- fire
- spear crafting
- shelter building
- sleeping

RIGHT SIDE
A live brain visualization that grows according to measured survival mastery.

IMPORTANT
The growing brain is a visualization of measured mastery.
It is NOT presented as literal physical neural-network size.

CADENCE HIGH-LEVEL ACTIONS
EXPLORE
GATHER_WOOD
GATHER_STONE
PICK_BERRIES
EAT
CRAFT_FIRE
CRAFT_SPEAR
HUNT_RABBIT
BUILD_SHELTER
SLEEP
WARM_UP

BODY CONTROLLER
Cadence chooses the high-level goal.
The game handles low-level movement to the selected target.

PERSISTENT FILES
cadence_stone_age_brain_v1.npz
cadence_stone_age_brain_v1_backup.npz
cadence_stone_age_stats.json
cadence_stone_age_runs.csv

Keep the .npz checkpoint file if you want the same Cadence brain to continue learning.

SETUP
Double-click setup.bat once.

RUN
Double-click run_stone_age.bat.

ESC
Save and quit.
